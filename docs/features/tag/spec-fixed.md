# 태그 기능 정의서

## 기능 개요

- 메모에 태그를 추가하고 관리할 수 있다.

## 기능 요구사항

- 메모에 태그를 추가할 수 있다.
- 메모에 추가된 태그를 삭제할 수 있다.
- 태그 목록을 메모 목록의 각 메모 안에서 확인할 수 있다.

## 주의사항

- 태그는 문자열로 저장한다.
- 중복 태그는 허용하지 않는다.

## 결정 사항

### 1. 태그는 목록의 각 메모 안에 표시한다

- 이 앱에는 상세 화면이 없고, 상세 화면을 새로 만들면 화면 전환 방식까지 정해야 해서 범위가 커지기 때문이다.
- 원본 정의서의 "노트 상세 화면"은 "메모 목록의 각 메모"로 바꾼다.

### 2. 중복은 앞뒤 공백을 제거하고 대소문자를 무시해서 판단한다

- 'React'와 'react '가 따로 쌓이면 같은 태그가 여러 개로 흩어져 중복 금지 규칙의 의미가 없어지기 때문이다.
- 저장은 입력한 표기 그대로 하고 앞뒤 공백만 제거한다. 사용자가 쓴 대소문자를 그대로 보여주기 위해서다.
- 중복은 한 메모 안에서만 판단한다. 다른 메모에 같은 태그가 있어도 된다.

### 3. 중복이거나 빈 값이면 입력란 아래에 오류 문구를 보여준다

- 아무 반응이 없으면 사용자가 입력이 실패한 것인지 알 수 없기 때문이다.
- 문구는 "태그를 입력하세요."(빈 값)와 "이미 있는 태그입니다."(중복)이다.
- 오류가 난 입력값은 지우지 않고, 다시 입력하기 시작하면 오류 문구를 지운다.

### 4. 메모마다 작은 입력란을 두고 Enter로 추가하며, 태그칩의 × 버튼으로 삭제한다

- 새 메모를 쓸 때만 태그를 넣게 하면 이미 있는 메모의 태그를 고칠 방법이 따로 필요하고, 입력란을 숨기면 클릭이 한 번 더 필요하기 때문이다.
- 기존 메모 추가 폼도 Enter로 제출하므로 같은 조작 방식을 유지한다.

### 5. 태그의 길이와 개수는 제한하지 않는다

- 원본 정의서에 없는 규칙이라 임의로 더하지 않기 위해서다.
- 긴 태그는 줄바꿈해서 표시한다.

### 가정

- 이미 저장된 메모에는 `tags`가 없으므로 빈 배열로 취급한다. 기존 데이터를 지우거나 바꾸지 않고 읽을 때만 보정하기 위해서다.

## 기술 결정

### 태그를 메모 목록의 각 항목 안에서 보여주고 입력받는다 (A안)

**상황**

- 원본 정의서는 "노트 상세 화면"에서 태그를 확인하도록 했지만, 이 앱에는 상세 화면이 없고 메모 목록만 있다.
- 메모는 `App`의 상태에 두고 `localStorage`의 `memos` 키에 통째로 저장한다. 하위 컴포넌트는 props로 받은 값만 그린다.

**다른 후보**

- B안: 메모를 누르면 상세 화면으로 이동하고, 거기서 태그를 확인·관리한다. 화면 전환 방식(라우터 또는 상태)을 새로 정해야 한다.
- C안: 목록에는 태그를 간단히 보여주고, 추가·삭제는 상세 화면에서 한다. B안의 비용에 목록 표시까지 더해진다.

**결정**

- A안으로 한다. `MemoItem` 안에 태그칩, 태그 입력란, 오류 문구를 두고, 태그 추가·삭제는 `App`의 콜백으로 처리한다. 태그는 메모의 `tags: string[]` 필드에 저장한다.

**결과**

- 장점
  - 새 화면과 라우팅 없이 기존 구조 그대로 구현할 수 있다.
  - 목록에서 바로 태그를 보고 고칠 수 있어 클릭이 적다.
  - 태그 규칙(`validateTag`)이 순수 함수라 단위 테스트로 검증한다.
  - 태그가 메모 데이터 안에 있어 메모를 지우면 태그도 함께 사라진다.
- 단점
  - 메모마다 입력란이 있어 목록이 길어지고 화면이 복잡해진다.
  - 태그를 바꿀 때마다 메모 전체를 `localStorage`에 다시 쓴다. 메모가 아주 많아지면 비효율적이다.
  - 상세 화면이 필요해지면 태그 UI를 다시 옮겨야 한다.
  - 태그가 메모 안에만 있어서 전체 태그 목록이나 태그 단위 통계를 보려면 모든 메모를 훑어야 한다.

## 이번엔 안 만들 것

- 태그 색상
- 태그 이름 수정 (고치려면 지우고 다시 추가한다)
- 자동완성
- 태그 여러 개 동시 필터

## 용어 정의

- **태그**: 메모에 붙이는 짧은 문자열 이름표. 앞뒤 공백을 제거해 저장하며, 한 메모 안에서 대소문자를 무시하고 중복될 수 없다.
- **태그칩**: 태그 하나를 작은 알약 모양으로 보여주는 화면 요소. 태그 이름과 삭제용 × 버튼으로 이루어진다.
- **태그 입력란**: 각 메모 안에 있는 입력창. 값을 쓰고 Enter를 누르면 태그가 추가된다.
- **필터**: 특정 태그가 붙은 메모만 골라 보는 기능. 이번 범위에는 포함하지 않으며 구현되어 있지 않다.
