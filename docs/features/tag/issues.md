# 태그 기능 이슈

기준 문서: `spec-fixed.md` (prd.md는 찾을 수 없어 사용하지 않았다)

## 이슈 1. 메모에 태그 추가/삭제

각 메모 안에서 태그를 붙이고 뗄 수 있다. 이 이슈만 끝내도 목록에서 태그칩이 보이고 입력란과 × 버튼으로 관리할 수 있다.

**완료 체크리스트**

- [ ] 메모의 태그 입력란에 값을 쓰고 Enter를 누르면, 앞뒤 공백이 제거된 태그칩이 그 메모에 추가된다.
- [ ] 태그칩의 × 버튼을 누르면, 해당 태그만 그 메모에서 사라진다.
- [ ] 같은 메모에 이미 있는 태그를 공백·대소문자만 다르게 입력하면, 태그는 추가되지 않고 입력란 아래에 "이미 있는 태그입니다."가 표시된다.
- [ ] 빈 값(공백만 포함)을 입력하고 Enter를 누르면, 태그는 추가되지 않고 "태그를 입력하세요."가 표시된다.
- [ ] 태그를 추가한 뒤 새로고침하면, 태그가 그대로 남아 있다. 태그가 없던 기존 메모도 오류 없이 표시된다.

## 이슈 2. 태그 클릭으로 메모 필터

태그칩을 눌러 그 태그가 붙은 메모만 모아 볼 수 있다. 이슈 1이 끝나 태그가 있는 상태를 전제로 하며, 이 이슈만 끝내도 화면에서 목록이 걸러지는 것을 확인할 수 있다. 태그 여러 개를 동시에 거는 필터는 만들지 않는다.

**완료 체크리스트**

- [ ] 메모 목록에서 태그칩을 누르면, 그 태그가 붙은 메모만 목록에 남는다.
- [ ] 필터가 걸려 있을 때, 현재 선택된 태그와 해제 방법(예: 해제 버튼)이 화면에 표시된다.
- [ ] 필터가 걸려 있을 때 해제하면, 모든 메모가 다시 목록에 나온다.
- [ ] 필터가 걸려 있을 때 다른 태그칩을 누르면, 이전 필터는 풀리고 새로 누른 태그로만 걸러진다.
- [ ] 선택한 태그가 붙은 메모가 하나도 남지 않게 되면(마지막 태그를 삭제한 경우 등), 빈 목록 안내가 표시되고 필터를 해제할 수 있다.
